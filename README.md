## Exercícios
- EX01 — Variables: apresenta dados usando strings, numbers, booleans, arrays e objects.
- EX02 — Conditions: classifica uma nota de 0 a 20.
- EX03 — Loops: demonstra contagem, soma, máximo e tabuada usando ciclos.
- EX04 — Functions: implementa add, subtract, multiply, divide, average, max e min.
- EX05 — Number Analyzer: identifica positivos, negativos, pares, ímpares, maior, menor e média.
- EX06 — String Laboratory: conta caracteres e palavras, inverte texto, procura uma palavra e verifica palíndromo.
- EX07 — Array Toolkit: implementa versões próprias de map, filter, find, reduce, includes e reverse.
- EX08 — Product Objects: permite pesquisar, filtrar e ordenar produtos.
- EX09 — Dynamic Table: cria linhas e células dinamicamente, permitindo adicionar, remover e atualizar estudantes.
- EX10 — Shopping Cart: permite adicionar, remover, alterar quantidades, calcular total e guardar dados em localStorage.
